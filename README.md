# Navigating Algorithmic Anxiety

This repository contains the project submissions for the **System Preparation Guide (SPG) Project - May 2026** by Team 52, as part of the BS in Data Science & Applications program at IIT Madras.

## Project Overview

**Project Title:** Navigating Algorithmic Anxiety: Evaluating the Role of a Growth Mindset in Managing Workplace Stress and Skill Obsolescence in the Age of Generative AI.

**Domain:** Resilience • Technological Literacy • Lifelong Learning • Stress Management • Growth Mindset

**Goal:** To evaluate how cultivating a growth mindset can help mitigate workplace stress, counteract perceived skill obsolescence, and prevent emotional exhaustion among working professionals adapting to advancing Generative AI integration.

**Scope:** Qualitative research via semi-structured interviews with working professionals across diverse domains.
